## Project Overview
This project is a Python data analysis practice project using the Netflix Movies and TV Shows dataset.  
The objective is to perform data cleaning, exploratory data analysis (EDA), and answer a series of analytical questions using Python and Pandas.

This project focuses on practicing core data analysis skills such as:
- Handling missing values
- Removing duplicates
- Filtering and querying data
- Grouping and aggregation
- Data visualization using bar charts and heatmaps

---

## Dataset Information

Source:  
Netflix Movies and TV Shows Dataset  
https://www.kaggle.com/datasets/shivamb/netflix-shows

The dataset contains 7,789 records and 11 columns:

- Show_Id
- Category
- Title
- Director
- Cast
- Country
- Release_Date
- Rating
- Duration
- Type
- Description

Some columns contain missing values, including:
- Director
- Cast
- Country
- Release_Date
- Rating

## Analysis Tasks

### Data Cleaning
1. Check and remove duplicate records.
2. Identify null values and visualize them using a heatmap.

### Analytical Questions

1. For "House of Cards", what is the Show Id and who is the Director?
2. In which year were the highest number of TV Shows and Movies released?
3. How many Movies and TV Shows are in the dataset?
4. Show all Movies released in the year 2000.
5. Show titles of TV Shows released only in India.
6. Top 10 Directors with the highest number of titles on Netflix.
7. Filter records based on Category, Type, and Country conditions.
8. In how many titles was Tom Cruise cast?
9. What are the different Ratings defined by Netflix?
10. How many Movies got 'TV-14' rating in Canada?
11. How many TV Shows got 'R' rating after 2018?
12. What is the maximum duration of a Movie/Show?
13. Which country has the highest number of TV Shows?
14. Sort the dataset by year.
15. Filter specific Category and Type combinations.
